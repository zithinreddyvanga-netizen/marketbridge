MARKETBRIDGE WEBSITE DEMO

1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome, Edge, Safari, or Firefox.

This is an interactive front-end demo. It stores demo data in the browser's local storage.
It does not yet include shared cloud accounts, real email delivery, live payment processing,
server-side AI, or production hosting. Those require backend setup.
